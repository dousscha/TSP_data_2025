# TSP_data_2025
# Human Performance in the Traveling Salesman Problem Is Influenced by the Spatial Scale of Target Configurations
# 🎮 Study Games and Raw Data Repository

This repo contains the **games developed for the study on unity ** as described in our manuscript and used by our participants, along with the **raw data** used for analysis.



## Overview

This repository contains the experimental data, video games, and analysis scripts associated with the study:

**"Human Performance in the Traveling Salesman Problem Is Influenced by the Spatial Scale of Target Configurations"**

Doussot, C., Muflih, S., Mailly, J., Müller, M.M., Boeddeker, N., and Lihoreau, M.

This repository provides the materials used for the experiments and subsequent analyses to support research transparency and reproducibility.

### 2. Experimental data

The datasets are organized into two directories.

**`Data/`**

Contains experimental raw data collected during the study.

**`Combined_data/`**

Contains processed and formatted datasets used for statistical analyses and figure generation.

The large raw trajectory dataset from Experiment 2 is also deposited on Zenodo:

**Zenodo:** https://doi.org/10.5281/zenodo.17433317

### 3. Analysis scripts

The `Analysis_scripts/` directory contains Python Jupyter notebooks and R scripts used for statistical analyses and figure generation.

The analyses include:

- Left-right preferences and route choices.
- Frequencies of transitions between targets.
- Relative error compared with optimal routes.
- Probability of selecting an optimal route.
- Effects of configuration scale, gaming habits, and trial number.
- Chest visibility and session duration.
- Generation of figures presented in the manuscript.

The Python notebooks are organized by analysis or figure, and the R scripts contain the statistical models and model comparisons.

### 5. Reproducing the analyses

To reproduce the statistical analyses and figures:

1. Download or clone this repository.
2. Install the required Python and R packages.
3. Use the formatted datasets in `Combined_data/` as inputs.
4. Open the corresponding Jupyter notebooks or R analysis scripts in `Analysis_scripts/`.
5. Update local file paths where necessary before running the scripts.

The processed datasets allow the downstream analyses to be performed without repeating the initial raw-data curation.

Some scripts may require intermediate output files generated by other analyses.
